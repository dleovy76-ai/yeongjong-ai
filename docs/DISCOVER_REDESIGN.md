# Discover 페이지 리디자인 (2026-08-26)

## 배경

랜딩 페이지에서 정한 디자인 토큰(cream/coral/ink/sky/terracotta, Gowun Dodum + Noto Sans KR)을
그대로 재사용해서 `/discover` 페이지(방문객용 Info AI 챗봇)를 다시 그렸다. Cowork(Claude)와 디자인
캔버스로 먼저 방향을 확인한 뒤 코드로 옮겼다.

## 변경 파일

- `frontend/tailwind.config.ts` — 색상 토큰 2개 추가: `sand`(#f4e9d8, AI 말풍선 배경),
  `paper`(#fffaf3, 채팅 카드 배경). 기존 cream/coral/ink 등은 그대로.
- `frontend/components/ChatWidget.tsx` — **공용 컴포넌트, 영향 범위 넓음** (아래 참고).
  - AI 메시지에 위치핀 아이콘 아바타(코랄 그라데이션 원) 추가.
  - 말풍선: AI는 sand 배경 + ink 텍스트, 사용자는 coral 배경 + 흰 텍스트, 둥근 모서리(꼬리 방향만
    살짝 좁힘).
  - 피드백 버튼: 기존 이모지(👍/👎)를 체크/X 아이콘(SVG)으로 교체. 디자인 시스템 규칙상 이모지
    대신 아이콘을 쓰기로 함.
  - 입력창: pill 모양, 코랄 포커스 테두리. 전송 버튼: coral pill.
  - 로직(상태, API 호출, 에러 처리)은 전혀 손대지 않음 — className과 마크업 구조만 변경.
- `frontend/app/discover/page.tsx` — 헤더에 배지("AI 여행 안내원") + coral-dark 헤드라인 +
  ink-muted 서브텍스트 추가. 추천 카드 목록을 흰 배경 rounded-2xl 카드 + coral pill 카테고리
  태그로 재구성. 로직은 원본과 동일.

## ⚠️ ChatWidget 공용 컴포넌트 영향 — 2026-08-26 결정 완료

`ChatWidget.tsx`는 discover 외에 아래 두 화면에서도 그대로 재사용된다. 이번 변경으로 그 화면들의
채팅창도 함께 바뀐다 (지난번 NavBar 색상 변경과 같은 상황).

1. `app/businesses/[id]/manager/page.tsx` — 사장님이 "AI 직원"(Manager AI)과 대화하는 화면
2. `app/businesses/[id]/page.tsx` — 방문객이 업체 상세페이지에서 Customer AI와 대화하는 화면

코드로 직접 확인한 결과, 두 화면 모두 헤더/본문은 `text-gray-600` 등 예전 톤 그대로고 채팅창만
코랄/샌드로 바뀐 상태다 (오너 확인 완료, "이대로 둔다"로 **결정**).

**결정: 이번엔 두 화면을 같이 손대지 않는다.** 이유는 NavBar 때와 동일 —
(a) 지금 최우선은 실제 파일럿 실행이지 전체 리브랜딩이 아님,
(b) 이 두 화면(특히 `businesses/[id]/page.tsx`)은 실제 예약/쿠폰/메뉴 흐름이 걸린, 이미 많이
테스트된 화면이라 레이아웃을 건드리면 불필요한 회귀 위험이 생김,
(c) 색상 토큰은 `tailwind.config.ts`에 이미 있으니 이 두 화면을 다시 손볼 다른 이유(기능 추가 등)가
생기면 그때 자연스럽게 같이 맞추면 됨 — 지금 미리 순서를 당길 필요는 없음.

"채팅창만 튀어 보이는" 정도는 실제로 깨진 게 아니라 단계적 롤아웃의 정상적인 중간 상태로 판단했다.
